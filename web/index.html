WebAssembly vs. JavaScript

C-Code, mit Emscripten zu WebAssembly kompiliert, im Vergleich zu denselben Algorithmen in JavaScript.

Lade WebAssembly-Module …
Test JavaScript Wasm -O3 Speedup -O3 Wasm -O0 Speedup -O0 Ergebnis gleich

Median aus mehreren Läufen nach einem Aufwärmlauf. Speedup = Zeit JavaScript / Zeit WebAssembly (> 1 bedeutet: WebAssembly ist schneller).
